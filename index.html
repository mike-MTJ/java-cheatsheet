Topic: Java Basics

Concept Syntax Description
Data Types int, double, boolean, char, String Basic data types in Java. int for integers, double for floating-point numbers, boolean for true/false, char for single characters, and String for text.
Variables int age = 25; Variables store data. Declare with a type and name, then assign a value.
If-Else 
if (condition) {
    // code
} else {
    // code
}
 Executes a block of code if a condition is true. Optionally, executes another block if the condition is false.
Loops 
for (int i = 0; i < 10; i++) {
    // code
}
 Repeats a block of code a specified number of times. for loops are commonly used for iteration.
Methods 
public void myMethod() {
    // code
}
 A block of code that performs a specific task. Methods can take parameters and return values.
Arrays int[] numbers = {1, 2, 3}; Stores multiple values of the same type in a single variable.
Classes 
public class MyClass {
    // fields, methods, constructors
}
 A blueprint for creating objects. Contains fields (variables) and methods.
Objects MyClass obj = new MyClass(); An instance of a class. Created using the new keyword.

Common Methods

Method Description
System.out.println() Prints text to the console and moves to the next line.
String.length() Returns the length of a string.
Math.max(a, b) Returns the larger of two values.
Arrays.sort(arr) Sorts an array in ascending order.
